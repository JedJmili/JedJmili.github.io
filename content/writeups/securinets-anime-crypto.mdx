## Overview

This is a full walkthrough of the cryptography track from an anime-themed Securinets
CTF. The track is split into three **waves**, each built around a different series:

- **Wave 1 — Naruto:** base encodings, classical ciphers and a first taste of XOR and RSA.
- **Wave 2 — Dragon Ball:** hash cracking, custom alphabets, AES brute force and multi-ciphertext XOR.
- **Wave 3 — Bleach:** the hard crypto — two RSA attacks and a five-stage boss chain.

Every flag is in the format `Securinets{...}`. Most challenges can be solved with
[CyberChef](https://gchq.github.io/CyberChef/) and a short Python script; a few need a
proper attack. Let's dive in.

### RSA — "The locked scroll"

> The Hokage locked a message inside a scroll. Only a few numbers were left behind:
> `p`, `e`, `n` and `c`.

**Handout**

```text
p = 1296333326819579802912748486794474979347921853878741592058033
n = 1958657156530162195397233766171134662374672377258645024116688975398225781870289852312741095725301989265784037356821871141
e = 65537
c = 380172567661716048869246684618070756994304686988313156582062525984487844857595183335729515137902498003444244905497269401
```

**A 60-second RSA refresher.** RSA security rests on the difficulty of factoring a large
modulus `n = p · q` into its two prime factors. A message `m` is encrypted as
`c = m^e mod n`. To decrypt you need the private exponent `d`, computed from the primes
via `d = e^(-1) mod φ(n)`, where `φ(n) = (p-1)·(q-1)`. Without the primes you can't get
`φ(n)`, so you can't get `d`.

The mistake here is that **`p` is handed to us directly**. Once you know one prime the
whole scheme collapses: `q = n / p`, then `φ(n)`, then `d`, then `m = c^d mod n`.

```python
from Crypto.Util.number import long_to_bytes

p = 1296333326819579802912748486794474979347921853878741592058033
n = 1958657156530162195397233766171134662374672377258645024116688975398225781870289852312741095725301989265784037356821871141
e = 65537
c = 380172567661716048869246684618070756994304686988313156582062525984487844857595183335729515137902498003444244905497269401

q = n // p
phi = (p - 1) * (q - 1)
d = pow(e, -1, phi)
m = pow(c, d, n)
print(long_to_bytes(m).decode())
```

You can also just paste the values into [dcode.fr](https://www.dcode.fr/rsa-cipher).

**Flag:** `Securinets{RSA_n0_jutsu_1s_th3_str0ng3st}`

### XOR — "Itachi still fighting"

> Naruto used **Rasengan** to defeat Itachi, but Itachi was still alive and fighting.
> HOW!!! XOR!!!

**Handout**

```text
ciphertext = 010410101c0e0f0b2612081c5e123e5a20522c510215525a36182c065a00091a0d501d3a031e3e361d332c025d090b1b26120618
```

**XOR** combines two byte streams bit-by-bit: a bit is `1` only when the two inputs
differ. It's reversible — `cipher XOR key = plaintext` and `plaintext XOR key = cipher`
— which makes it a cheap symmetric cipher when a key is repeated across the message.

The description bolds **Rasengan**, and that's the repeating key. XOR the hex ciphertext
with the ASCII bytes of `Rasengan`:

```python
ct = bytes.fromhex("010410101c0e0f0b2612081c5e123e5a20522c510215525a36182c065a00091a0d501d3a031e3e361d332c025d090b1b26120618")
key = b"Rasengan"
print(bytes(b ^ key[i % len(key)] for i, b in enumerate(ct)).decode())
```

**Flag:** `Securinets{y0u_4r3_4lr34dy_c4ght_1n_my_XOR_g3njutsu}`

## Wave 2 — Dragon Ball

### Spirit Bomb — "Break the hash"

> Goku is preparing the Spirit Bomb. A mysterious hash has appeared, containing the
> secret needed to open a RAR archive.

**Handout:** an MD5 hash `2855c6adc42ad82414a2eea7c128fbac` and a password-protected archive.

**What's a hash?** A cryptographic hash like **MD5** maps any input to a fixed-length
digest and is designed to be one-way — you can't reverse it mathematically. But MD5 is
fast and unsalted, so for common passwords you can just look the digest up (or brute
force it). Feed the hash to [CrackStation](https://crackstation.net) or run hashcat
against `rockyou.txt`:

```bash
hashcat -m 0 -a 0 hash.txt rockyou.txt
```

The cracked password opens the archive, which contains a **Dancing Men** cipher (the
Sherlock Holmes stick-figure alphabet). Decode that with the Dancing Men tool on
[rumkin.com](https://rumkin.com/tools/cipher/) to get the flag.

**Flag:** `Securinets{g0ku_n33ds_y0ur_H4sH_sp1r1t_b0mb}`

### Saiyan Saga — "Bruteforce the power level"

> Goku showed his new power, **AES** Kaioken. The Saiyans used their scouters to
> **bruteforce** his power level.

**Handout**

```json
{
  "ciphertext": "dd7d9225d5d724381ab07ea9830ea6792a8a91740c05a053da9f7d40e3769014c7626ecb629de978085ce5e6714604f4",
  "iv": "8845a59d499ae2cbe0f90b35393656fe",
  "mode": "AES-CBC",
  "key_derivation": "MD5(password)",
  "hint": "The password is 4 digits."
}
```

**AES** is the standard symmetric block cipher (128-bit blocks). In **CBC** mode each
plaintext block is XORed with the previous ciphertext block before encryption, and the
first block uses the **IV** (initialization vector). To decrypt you need the key — here
the key is `MD5(password)` and the password is only **4 digits**.

That's just 10,000 possibilities (`0000`–`9999`), so we brute force: derive the key from
each candidate, decrypt, and stop when the PKCS#7 padding is valid *and* the plaintext
starts with `Securinets{`.

```python
from Crypto.Cipher import AES
from Crypto.Util.Padding import unpad
from hashlib import md5
import json

data = json.load(open("challenge.json"))
ciphertext = bytes.fromhex(data["ciphertext"])
iv = bytes.fromhex(data["iv"])

for pin in range(10000):
    password = f"{pin:04d}"
    key = md5(password.encode()).digest()
    try:
        pt = unpad(AES.new(key, AES.MODE_CBC, iv).decrypt(ciphertext), AES.block_size)
        if pt.startswith(b"Securinets{"):
            print("PIN:", password, "->", pt.decode())
            break
    except ValueError:
        pass  # wrong key -> bad padding
```

The correct PIN is `9125`.

**Flag:** `Securinets{1ts_0v3r_n1n3_th0us4nd_p0w3r_l3v3l}`

```python
key = b"Genkidama"

cts = [
    "1700011b050141020767200f191d0c404c4117090b0a1a014d4d062e130b4b040141140e32174e0e0701130a186644",
    "14000b4b100b144d0d26110b1945442c0c0b2e0b4e291c114f",

]

def repeating_xor(data, key):

    print(repeating_xor(bytes.fromhex(h), key))
```

### Mayuri Kurotsuchi — "RSA with two exponents"

```text
c2 = 99251096002253562403593501119497643127110349802229731167445716552415600714194190730009853439818922834061026977819922798480723517120990011565521065279048001519805739886381029993544771196890004485617904652361965516732936730718195921770298603335239139273527471440674095809914314579791323448686676482481556853194
```

The same `m` is encrypted under the **same modulus** with two **coprime** exponents.
This is the classic **common-modulus attack** — no factoring needed. Because
`gcd(e1, e2) = 1`, the extended Euclidean algorithm gives integers `a, b` with
`a·e1 + b·e2 = 1`. Then:

```text
c1^a · c2^b ≡ m^(a·e1) · m^(b·e2) ≡ m^(a·e1 + b·e2) ≡ m^1 ≡ m   (mod n)
```

For `e1 = 3, e2 = 5` we get `a = 2, b = -1`, i.e. `m ≡ c1² · c2^(-1) (mod n)`. The
negative exponent is fine — Python's `pow(x, -1, n)` computes the modular inverse (it
exists because `gcd(c2, n) = 1`).

```python
from Crypto.Util.number import long_to_bytes

def egcd(a, b):
    if b == 0:
        return a, 1, 0
    g, x, y = egcd(b, a % b)
    return g, y, x - (a // b) * y

g, a, b = egcd(e1, e2)
assert g == 1, "exponents must be coprime"

m = (pow(c1, a, n) * pow(c2, b, n)) % n   # pow handles the negative exponent
print(long_to_bytes(m).decode())
```

**Flag:** `Securinets{m4yur1_14b_p3rm1ss10n_gr4nt3d}`


Here `e = 3` and the message is short, so `m^3` is **smaller than `n`** — the modular
reduction never happens and `c = m^3` over the integers. This is the **small-exponent
(cube-root) attack**: just take the integer cube root of `c`. We use an integer binary
search so there's no floating-point rounding error on a number this large.

```python
from Crypto.Util.number import long_to_bytes

def iroot(x, k):           # exact integer k-th root via binary search
    lo, hi = 0, 1 << ((x.bit_length() // k) + 1)
    while lo < hi:
        mid = (lo + hi + 1) // 2
        if mid ** k <= x:
            lo = mid
        else:
            hi = mid - 1
    return lo

m = iroot(c, 3)
assert m ** 3 == c, "not a perfect cube — m^3 wrapped around n after all"
print(long_to_bytes(m).decode())
```

**Flag:** `Securinets{4ll_4cc0rd1ng_t0_41z3ns_pl4n}`

### Getsuga Tenshō — "Guess it character by character"

> *Don't even think of guessing the flag — it's 33 characters long!*

**Handout**

```python
flag = "................................."   # 33 chars, hidden on the server
user_input = input()
index = 0
for char in user_input:
    if char != flag[index]:
        print("Wrong flag!")
        exit()
    index += 1
print("Correct flag!")
print("flag is : Securinets{" + user_input + "}")
```

The check is a **character-by-character comparison** that bails on the first wrong
character. That leaks the flag one position at a time: if the current guess is correct so
far it accepts another character; otherwise it prints `Wrong flag!`. So we brute force
each position independently — at most `charset × 33` connections instead of
`charset^33`.

```python
from pwn import remote

HOST, PORT = "127.0.0.1", 31337
charset = "abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789_{}"
flag = ""

for i in range(33):
    for c in charset:
        io = remote(HOST, PORT)
        io.sendline((flag + c).encode())
        resp = io.recvall(timeout=2).decode(errors="ignore")
        io.close()
        if "Correct flag!" in resp:
            flag += c
            print(f"[+] {i + 1}/33: {flag}")
            break

print("Securinets{" + flag + "}")
```

### Bankai — "Five barriers"

> Five barriers stand between Ichigo and the Central 46 archive. Bankai won't help you.
> Your brain might.

This is the boss: a single service that walks you through **five stacked layers**, each
one producing the key for the next.

**Stage 1 — SENKAIMON (Caesar).** `EVYRLF=GHUWHRBAV`. A Caesar cipher; shifting back by
7 gives `XORKEY=ZANPAKUTO`.

**Stage 2 — ZANPAKUTO (XOR).** `0c08091b0412680707130f071700061c`. XOR the hex against the
key `ZANPAKUTO` from stage 1:

```python
ct = bytes.fromhex("0c08091b0412680707130f071700061c")
key = b"ZANPAKUTO"
print(bytes(b ^ key[i % len(key)] for i, b in enumerate(ct)))   # VIGKEY=SHINIGAMI
```

**Stage 3 — SHIKAI (Vigenère).** `SLAXME=ZMVYLBFCQEK12345`. A Vigenère cipher with key
`SHINIGAMI` (from stage 2) decrypts to `AESKEY=ZANGETSUKEY12345`.

**Stage 4 — BANKAI (AES-CBC bit-flipping).** The session cookie is AES-CBC encrypted and
contains `role=shinigami`; we need `role=quincy`. You **don't need the key** — CBC
decryption XORs each plaintext block with the previous ciphertext block, so flipping a
byte in the previous block (or in the IV, for the first block) flips the same position in
the decrypted plaintext. The relationship is:

```text
new_prev_byte = old_prev_byte XOR old_plaintext_byte XOR desired_plaintext_byte
```

Locate the 16-byte block holding the role, apply that XOR to each differing byte of the
preceding block, leave everything else untouched, and send the tampered IV + ciphertext
to the oracle. It now decrypts as `role=quincy`.

**Stage 5 — HOGYOKU (RSA, e = 3).** The final layer is the same small-exponent RSA as
*RSAnt*: `c = m^3` with `m^3 < n`, so take the integer cube root of `c` to recover the
plaintext.

Clear all five and the archive opens.

**Flag:** `Securinets{b4nk4i_br0k3_th3_h0gy0ku}`

## Takeaways

A few patterns run through the whole track and are worth internalizing:

- **Read the flavour text.** Bolded words (`Rasengan`, `SHARINGAN`, `Genkidama`, the
  Earth chant) were literally the keys. The challenge titles named the technique.
- **XOR is everywhere** and it's symmetric: known plaintext XOR ciphertext hands you the
  key for free.
- **RSA fails at its edges**, not its core — a leaked prime, a shared modulus with
  coprime exponents, or an exponent so small the message never wraps the modulus. None of
  these require factoring.
- **Brute force is fine when the space is tiny** — 10,000 PINs, 25 Caesar shifts, or a
  flag that leaks one character at a time.
